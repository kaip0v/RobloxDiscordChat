# Roblox Discord Chat Overlay

Локальный чат-оверлей, который выводит сообщения из Discord поверх экрана в классической стилистике чата Roblox. Поддерживает систему вкладок, автоматическую синхронизацию, RolePlay-режим и верификационные бейджи.

## Системные требования
Для работы плагина-моста необходимо использовать модифицированный клиент Discord — **[Vencord](https://vencord.dev/)**. Стандартный клиент Discord не поддерживает пользовательские плагины.

## Установка и запуск

1. **Скачивание:** Перейдите в раздел [Releases](https://github.com/kaip0v/RobloxDiscordChat/releases/latest) и скачайте актуальный файл установщика (например, `Roblox Overlay Setup 1.0.0.exe`).
2. **Установка Оверлея:** Запустите скачанный `.exe` файл. Приложение автоматически установится на ваш ПК и незаметно скачает нужный плагин в системную директорию Vencord.
3. **Активация в Discord:**
   * Откройте клиент Discord.
   * Перейдите в **Настройки (User Settings)** -> пролистайте вниз до раздела **Vencord** -> выберите **Plugins**.
   * Введите в поиск **RobloxChatOverlay** и включите его тумблером.
   * Полностью перезагрузите Discord комбинацией клавиш `Ctrl + R`.

## Использование оверлея

При первом запуске откроется окно базовых настроек. Скопируйте ID канала, из которого вы хотите читать сообщения (ПКМ по каналу -> Копировать ID канала), и вставьте его в соответствующее поле.

**Управление:**
* Открыть окно ввода текста: `Alt + /` (или ваша кастомная кнопка из настроек).
* Скрыть окно ввода: `Escape` или клик в любое пустое место экрана.
* Открыть настройки: Кнопка `⇄` на боковой панели оверлея.
* Добавить новую вкладку: Скопируйте ID нужного канала в буфер обмена и нажмите кнопку `+` на боковой панели оверлея.
