# Roblox Discord Chat Overlay

Локальный чат-оверлей, который выводит сообщения из Discord поверх экрана в классической стилистике чата Roblox. Поддерживает систему вкладок, автоматическую синхронизацию, RolePlay-режим, верификационные бейджи и быстрый переход в личные сообщения по клику.

## Системные требования
Для работы плагина-моста необходимо использовать модифицированный клиент Discord — **[BetterDiscord](https://betterdiscord.app/)**. Стандартный клиент Discord не поддерживает пользовательские плагины.

## Установка и запуск

1. **Скачивание:** Перейдите в раздел [Releases](https://github.com/kaip0v/RobloxDiscordChat/releases/latest) и скачайте актуальный файл установщика (например, `Roblox Overlay Setup 1.0.1.exe`).
2. **Установка Оверлея:** Запустите скачанный `.exe` файл. Приложение автоматически установится на ваш ПК и незаметно скачает нужный плагин в системную директорию BetterDiscord.
3. **Активация в Discord:**
   * Откройте клиент Discord.
   * Перейдите в **Настройки (User Settings)** -> пролистайте вниз до раздела **BetterDiscord** -> выберите **Плагины (Plugins)**.
   * Найдите в списке **RobloxChatOverlay** и включите его тумблером.
   * Полностью перезагрузите Discord комбинацией клавиш `Ctrl + R`.

## Использование оверлея

При первом запуске откроется окно базовых настроек. Скопируйте ID канала, из которого вы хотите читать сообщения (Включите режим разработчика в Discord -> ПКМ по каналу -> Копировать ID канала), и вставьте его в соответствующее поле.

**Управление и функции:**
* **Открыть окно ввода текста:** `Alt + /` (или ваша кастомная кнопка из настроек).
* **Скрыть окно ввода:** `Escape` или клик в любое пустое место экрана.
* **Открыть настройки:** Кнопка `⇄` на боковой панели оверлея.
* **Добавить новую вкладку:** Скопируйте ID нужного канала в буфер обмена и нажмите кнопку `+` на боковой панели оверлея.
* **Быстрые ЛС:** Кликните по никнейму любого пользователя прямо в оверлее, и Discord моментально переключится на личную переписку с ним.
